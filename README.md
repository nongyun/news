# 📰 全球头条·每日热点新闻站

自动聚合军事、娱乐、科技、汽车、NBA、足球等国内外头条新闻，每日定时更新，生成静态网站。

## 功能特性

- 自动采集 RSS 源（中国新闻网、ESPN/BBC 等）
- 可选集成 GNews API 获取更丰富内容
- 生成 SEO 友好的静态 HTML 页面
- GitHub Actions 每日自动运行，无需人工干预
- 适配 Cloudflare Pages 部署
